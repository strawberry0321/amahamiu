- 🌐 在线访问：https://strawberry0321.github.io/amahamiu/
- 📦 仓库地址：https://github.com/strawberry0321/amahamiu

## 项目结构

| 文件 | 说明 |
|------|------|
| `index.html` | 网站主页，包含页面结构、渐变呼吸背景与星星粒子效果 |
| `.gitignore` | 指定 git 忽略的本地文件（如 `.tools/`） |

## index.html 各部分功能说明

| 部分 | 功能 |
|------|------|
| `<!DOCTYPE html>` | 声明 HTML5 文档类型 |
| `<html lang="zh-CN">` | 声明页面语言为简体中文，利于 SEO 与无障碍阅读 |
| `<meta charset="UTF-8">` | 设置字符编码，避免中文乱码 |
| `<meta name="viewport">` | 视口适配，使页面在移动端按设备宽度正确显示 |
| `<title>My Page</title>` | 浏览器标签页标题 |
| `<style>` 中的 `body` 样式 | 清除浏览器默认边距、占满视口高度、设置粉色渐变背景（主色 `#F4C0D2`） |
| `<style>` 中的 `@keyframes breathing` | 呼吸动画关键帧：渐变背景 8 秒一个周期往复流动，形成动态呼吸效果 |
| `<style>` 中的 `#starfield` 样式 | 星星画布固定铺满视口、鼠标事件穿透、悬浮于背景之上 |
| `<canvas id="starfield">` | 星星粒子的绘制画布 |
| `<script>` 中的星星粒子脚本 | 按屏幕面积随机生成星星，正弦闪烁、缓慢漂浮、边缘环绕，随窗口缩放自适应 |
| `<body>` | 页面可见内容区域，当前仅包含星星画布，正文内容后续在此扩展 |

### [2026-08-28 18:40] 渐变呼吸背景

- **修改**：背景由纯色升级为粉色系渐变（主色 `#F4C0D2`，向浅粉 `#FADCE6` / 深粉 `#F7A8C4` 过渡）。
- **增加**：新增 `breathing` 呼吸动画 —— 渐变背景以 8 秒为周期、`ease-in-out` 缓动往复流动，呈现类似"吸气-呼气"的动态呼吸效果，无限循环。

### [2026-08-28 18:44] 星星粒子效果

- **增加**：新增 `<canvas id="starfield">` 画布与配套 JS 脚本，在渐变背景上绘制漂浮闪烁的星星粒子。
  - 星星密度随屏幕面积自适应（约每 9000 平方像素 1 颗），大小、亮度、闪烁速度、相位均随机；
  - 透明度按正弦规律周期变化产生闪烁，带柔和光晕，整体缓慢向上漂浮、左右轻摆；
  - 飘出边界的星星从对侧环绕回归，窗口缩放时自动重建。
- **增加**：`body` 添加 `overflow: hidden` 防止粒子溢出产生滚动条；`#starfield` 设置 `pointer-events: none` 保证鼠标交互穿透。

### [2026-08-28 19:01] 星星尺寸放大

- **修改**：星星尺寸放大 —— 半径范围由 0.4~2.0 像素调整为 1.2~3.6 像素，使白点在粉色背景上更清晰可见。
